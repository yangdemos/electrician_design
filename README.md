# HARBOURLINE ELECTRICAL · 港湾电气

住宅电工咨询报价网站首版。位置：D:\电工网。

## 预览
- 公开网站：https://yangdemos.github.io/electrician_design/
- 当前预览：http://127.0.0.1:5186/
- 在此文件夹运行 `npm.cmd run dev` 或 `node server.cjs`，然后打开上述地址。
- 也可双击 index.html 查看；无需安装依赖。
- 若端口被占用，先查看该地址是否已有港湾电气预览，避免重复启动。

## 已实现
- 暗桃色视觉、抽象背景纹理与 Canvas 光线轨迹。
- 首次访问欢迎弹窗、关闭及会话记忆，页脚可以重看欢迎语。
- 新房整包、电器安装、电路维修、旧房改造四类可展开服务。
- David、petter、daniel、Sun、sky 五人相册，悬浮和键盘焦点显示简介，手机可横向滑动。
- 五个独立人物详情页面，可以携带成员和服务类型进入咨询表单。
- 表单必填和邮箱验证、生成清单、下载 UTF-8 文本。所有输入仅在当前页面处理。
- FAQ、隐私及使用说明、手机导航、减少动态效果设置支持。
